# Product context

OQVIAN PERIVANT is a defensive product demonstration for understanding changes to an approved infrastructure baseline. The fictional ASTERGATE CLOUD SERVICES inventory makes the experience concrete without implying that real customer infrastructure was scanned.

The demo answers: what is in scope, what was expected, what changed, whether there is a matching approval, what evidence supports the finding, and who should investigate it. It distinguishes locally observed service state from synthetic DNS and certificate metadata.

Potential audiences include managed service providers, internal security operations teams, IT infrastructure groups, and security consultants. The current demo is not a production external attack surface scanner or a multi-tenant service.
